# CARTOSOUND™ 4D Module Overview

https://bwiildita.sharepoint.com/sites/prod/Topics/CARTSOUND\_4D\_Overview\_EN.xml

The CARTOSOUND™ 4D Module combines 3D real-time ultrasound image data with CARTO™ 3 System Maps.

The real-time ultrasound images are displayed in the CARTO™ 3 System and in the GE Healthcare Vivid S70N (Vivid S70N) ultrasound system.[[1]](#footnote-2)

4D images are real-time volumetric images with a field of view of up to 90°×90°. 4D multi-planar and 2D ultrasound images are acquired with the compatible NUVISION™ NAV Ultrasound Catheter. The catheter includes an ultrasound transducer and a location sensor.

This module also enables acquisition of clips from the ultrasound system. The user can draw contours of the required anatomy on any frame of the ultrasound clip and add this information to a 3D reconstruction. The ultrasound clip can be saved with these contours, with the frames containing the contours marked for easy identification. A clip can also be saved for future contouring. Contour data contributes anatomical information to the map. Contours and Ultrasound clips are listed in the Point List.

## About the NUVISION™ NAV Catheter

https://bwiildita.sharepoint.com/sites/prod/Topics/CARTOSOUND4D\_Nuvision\_Nav\_EN.xml

Working with the CARTOSOUND™ 4D Module requires use of the NUVISION™ NAV Ultrasound Catheter. NUVISION™ NAV catheter integration enables the same location detection as other magnetic-based location catheters, with no need for additional registration to the streaming ultrasound.

The NUVISION™ NAV Ultrasound Catheter (10 F or 10.5 F) is a sterile, single-use, disposable diagnostic ultrasound imaging catheter designed for intracardiac use. The distal tip of the catheter contains a 4D ICE ultrasound transducer, for real-time 2D, 3D, and multiplane intracardiac imaging. It is coupled with a sensor, providing 3D location information to the CARTO™ 3 System with ultrasound capability. Knobs on the catheter handle enable deflecting the catheter shaft and rotating the transducer array independently of the deflection of the catheter shaft. The imaging field emanates from one side of the catheter tip, perpendicular to the axis of the catheter. Refer to the *NUVISION™ NAV Catheter Instructions for Use* for further information.

### Bi-Plane Mode

## Orientation Markers

https://bwiildita.sharepoint.com/sites/prod/Topics/CS4D\_orientation\_markers\_EN.xml

In 2D, Multi-Plane, and 4D Advanced modes, there are orientation markers located at the bottom left side of each imaging plane and in the 3D image. The colors of the markers in the planes and in the 3D image correspond with the frame colors. The markers in the planes remain static when the 3D image is manipulated. This ensures accurate interpretation.

Orientation markers are active by default. You can deactivate them by deselecting the Orientation Marker setting in the Display Settings Menu.
