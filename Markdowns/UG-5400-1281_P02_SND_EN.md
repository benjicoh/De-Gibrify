# CARTOSOUND™ Module Overview

https://bwiildita.sharepoint.com/sites/prod/Topics/cartoSound\_intro\_v7\_EN.xml

The **CARTOSOUND™ Module** combines real-time ultrasound image data with CARTO™ 3 point-by-point maps. Ultrasound images are acquired with a supported catheter from the SOUNDSTAR™ Ultrasound Catheter family (referred to as the SOUNDSTAR™ Catheter). These catheters include an ultrasound transducer and a Biosense Webster location sensor. The ultrasound transducer emits and receives multiple rays of ultrasound. The real-time ultrasound images are displayed in the CARTO™ 3 System, as well as on a compatible ultrasound system.[[1]](#footnote-1)

Once the streaming ultrasound is stopped, a 3-second video clip is displayed. You can then draw contours of the required anatomy on any frame of the ultrasound clip and add this information to a 3D reconstruction. The 3-second ultrasound clip is saved with these contours, and the frames containing the contours are marked for easy identification. Contour data contributes anatomical information to the map. Contours are listed in the Point List.

## Working with the CARTOSOUND™ Module

https://bwiildita.sharepoint.com/sites/prod/Topics/CARTOSOUND\_using\_V8p2\_EN.xml

A SOUNDSTAR™ Catheter is displayed in the Main Map Viewer or the Additional Map Viewer with an outline representing the ultrasound fan. The catheter's tip position can be displayed in either Stable or Gated visualization mode.

* Stable -To present and acquire a stable location during the cardiac cycle, location is calculated as the average of the real-time locations detected during the previous second.
* Gated - To present and acquire a specific timing during the cardiac cycle, the location is taken at the annotation time.

Electroanatomical (EA) points can be acquired in either Stable or Gated mode. If you want to combine EA points and contours, it is recommended to draw the contours before acquiring EA points.

The catheter's 3D image can be displayed in either Real Time or Gated mode.

![cartosound_cath_mapViewer.png](data:image/png;base64...)

Figure 1: Ultrasound Catheter Tip Position (1) and 3D Image (2)

CARTOSOUND™ Maps can be combined with FAM maps, using the Anatomical Merge feature.

The CARTOSOUND™ Module provides the following advantages:

* **Near real-time anatomical mapping:** Unlike pre-acquired MRI or CT scans, ultrasound images provide real-time anatomical information. The CARTOSOUND™ Module lets you mark specific areas on pre-selected ultrasound frames and integrates them with CARTO™ 3 System 3D anatomical reconstructions.
* **Enhanced catheter navigation:** By combining the accurate location capabilities of the CARTO™ 3 System with the real-time ultrasound images, you can visualize the location of the ablation catheter during a study with the CARTOSOUND™ Module. Using ultrasound during a study provides another layer of information for mapping anatomical locations that are traditionally difficult to navigate to.
* **Enhanced understanding of ultrasound images:** With the CARTOSOUND™ Module, the system can superimpose maps and display the catheter icon on ultrasound images, to contribute to the identification of anatomic structures in the ultrasound image.
* **Real-time Visualization of Complex Anatomies:** When the ultrasound transducer is directed at an area of interest in the heart, the system can visualize complex anatomies.
* **Enhanced Image Integration:** Some treatment strategies require MRI or CT scans to assess the anatomy, variation, and pathologies of the heart. The CARTOMERGE™ Module enables integrating MR or CT images with CARTO™ 3 Maps to provide precise 3D intracardiac anatomical information integrated with electrophysiological data acquired by the CARTO™ 3 System. Using the CARTOSOUND™ Module, you can register the pre-acquired images with maps that include ultrasound data.

It is recommended to use the CARTOSOUND™ Module with the Respiration Gating feature[[2]](#footnote-2). For details, refer to the *Comprehensive User Guide*.

## About the SOUNDSTAR™ Ultrasound Catheter Family

https://bwiildita.sharepoint.com/sites/prod/Topics/About the SoundStar 3D Catheter\_EN.xml

When working with the CARTOSOUND™ Module, you must use a supported catheter from the SOUNDSTAR™ Ultrasound Catheter family (referred to as the SOUNDSTAR™ Catheter). These catheters incorporate a pre-calibrated Biosense Webster location sensor, which enables the same location detection of a SOUNDSTAR™ Catheter as for a focal ablation mapping catheter, with no need for additional registration to the streaming ultrasound.

There are several versions of the SOUNDSTAR™ Catheter[[3]](#footnote-3), compatible with GE and Siemens ultrasound systems:

* SOUNDSTAR™ 3D 10 F Diagnostic Ultrasound Catheter
* SOUNDSTAR™ eco 10 F Diagnostic Ultrasound Catheter
* SOUNDSTAR™ eco 8 F Diagnostic Ultrasound Catheter
* SOUNDSTAR CRYSTAL™ 9 F Ultrasound Catheter

The ultrasound catheter is connected to the ULTRASOUND Catheter socket on the Patient Interface Unit (PIU). You can choose to work with only an ultrasound catheter, or with both an ultrasound catheter and a focal ablation catheter connected to the PIU.

# Safety Considerations

https://bwiildita.sharepoint.com/sites/prod/Topics/CSound\_Safety\_EN.xml

The intended use of the CARTO™ 3 System is catheter-based cardiac electrophysiological (EP) procedures. The CARTO™ 3 System provides information about the electrical activity of the heart and about catheter location during the procedure. The system can be used on patients who are eligible for a conventional electrophysiological procedure.

The system has no specific contraindications.

When using the System with the CARTOSOUND™ module, all instructions relating to use of the CARTOSOUND™ Module must be followed to ensure proper accuracy and safety.

## Contours in CARTO™ 3 System Maps

https://bwiildita.sharepoint.com/sites/prod/Topics/Understanding Maps that Include Ultrasound Contours\_EN.xml

Ultrasound images are relayed from the ultrasound system to the CARTO™ 3 System, where they are displayed in real time. The Ultrasound window is used to pause real-time imaging and display a 3-second video clip. A marker in the Ultrasound window indicates the frames of the clip that are gated to the end-expiration phase and to the maximal LA volume (end of the T wave ±2 frames). (See ["Creating an Ultrasound Clip"](#target9000001).)

The System supports the following volume of contour data, with frames and stored clips counted as contours:

* 100 unique clips acquired during a single study
* 50 contours saved in a single clip
* 200 saved contours in a single map
* 400 saved contours in a single study

You can then draw a contour outlining a structure of interest and assign the contour to a specific map. The contour is made up of a series of points that approximately delineate the desired anatomical shape when added to a map. Contours contribute only location information to a map. No electrical data is acquired from a contour. Each contour added to a map is listed in the Point List (indicated by an ultrasound icon).

There are two types of contours:

|  |  |
| --- | --- |
| Normal | A normal contour contributes directly to the anatomical shape of a map. Normal contours are included in surface registration. |
| Floating | Floating contours are displayed in space relative to the map, and do not contribute to the map itself. When using CARTOMERGE™ Module, floating contours are not calculated in surface registration. |

As contours are added to a map, the reconstruction is created in the same manner as with standard points acquired with a mapping catheter. The map is updated in the Main Map Viewer (and Additional Map Viewer, if open).

You can mark contours with Contour Tags or OS Tags to label anatomical structures. Contour Tags add a color and label to an anatomical structure such as the LIPV. OS Tags use colored dots at the beginning of the line to mark the ostium, valves, artery, or appendage. (See: ["Tagging Contours"](#target9000002).)

Electrical data is acquired only via a Biosense Webster mapping catheter. If point data is acquired with a mapping catheter, the electroanatomical information is added to the reconstruction. Color is applied to maps in the standard manner. Map shape is recalculated as points and contours are added to the reconstruction.

### Auto Draw

https://bwiildita.sharepoint.com/sites/prod/Topics/CSound\_Autodraw\_Options\_EN.xml

Instead of drawing a contour manually, you can extract a contour from a frame automatically. Using Auto-draw, the system detects edges in the selected ultrasound frame, and automatically draws a contour. After you verify that the contour is acceptable, and adjust as necessary, you can assign the contour to a specific map in the same manner as a manually drawn contour.

Contours are drawn automatically in one of two ways:

* By using the automatic threshold option.
* By setting the edge detection threshold manually.

The threshold filters the initial (Canny) edges of the ultrasound image not visible to the user. These initial edges act as anchors for the final edges of the contour.

A low threshold sets the final edges according to relatively weak initial edges. Such edges might appear inside the cavity as noise or at the border of the cavity where the contrast is low.

Examine the image before selecting the threshold. If there is high noise inside the cavity, increasing the threshold might help to create a more accurate automatic contour. On the other hand, if the image is not noisy but has low contrast, decreasing the threshold might provide a better contour.

Automatic Threshold

You can create automatic contours without selecting a threshold (no bars displayed with the Auto Draw cursor). The system examines the area of interest, and creates a contour or contours based on the detected contrast, brightness, and noise detected.

Manually Setting the Threshold

The Auto Draw tool has 3 different thresholds. After selecting ![uls7-5_autodraw.png](data:image/png;base64...), the thresholds are indicated by 1-3 red bars displayed with the Auto Draw cursor when using the mouse scroller.

One bar indicates the lowest sensitivity (high threshold). Three bars indicate the highest sensitivity (low threshold).

Use a higher sensitivity when the frame is noisy (with many shades of gray). Use a lower sensitivity when the frame has sharp contrasts.
