# CARTOREPLAY™ Module Overview

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_intro\_v4-3\_EN.xml

The **CARTOREPLAY™ Module** records all ECG data and electrode location data (magnetic or ACL) for all connected catheters throughout the procedure. The recorded data can be accessed at any time during the study to view earlier ECG signals and catheter positions, and to retroactively acquire additional points for EA mapping.[[1]](#footnote-1)

It is also possible to retroactively capture signals (IS for PASO™ Module or body surface patterns for CONFIDENSE™ Module). Intracardiac patterns cannot be captured retroactively.

The CARTOREPLAY™ Module includes dual monitor support, which can be used to extend the display across two monitors for more convenient viewing.

The CARTOREPLAY™ Module supports all the other CARTO™ 3 System modules.

A Biosense Webster representative is responsible for the installation and initial configuration of the module.

## Timeline Mode

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_replayMode\_v7\_EN.xml

During a study performed with the CARTOREPLAY™ Module, two display modes are available.

* **Real-time mode**: Viewers display current activity and data
* **Timeline mode**: The Monitor pane displays ECG signals and system indications from a selected time in the study. The map viewers display catheter positions from that selected time.

Timeline mode can be used for the following workflows:

* **Extended Beat Buffer**: You just missed acquiring a point. Scroll back in the Monitor pane to acquire the point.
* **Exploratory review**: Use Timeline mode to review and explore an earlier time in the study. If necessary, acquire additional points.
* **Review of selected events**: Events such as point acquisition, ablation sessions, and pacing are displayed in the event panel. You can scroll through events of the same type.

In the context of this module, an event may be instantaneous (acquisition of EA points or ultrasound contours) or of longer duration (ablation, pacing, respiration status).

Timeline mode is not available during the following processes:

* Ablation: If you start ablation in Timeline mode the system automatically reverts to Real-time mode.
* Continuous acquisition: You must end FAM acquisition or continuous EA acquisition before you can activate Timeline mode.
* When a propagation map is displayed in Timeline mode, the option to display a propagation map is disabled.

Real-time acquisition is not available in Timeline mode. Exit the mode to acquire points or FAM data.

If you hide the Monitor Pane, the system automatically reverts to Real-time mode.

See also:

* ["Retroactive Point Acquisition"](#target9000001)

## Activating Timeline Mode

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_activate\_v7\_EN.xml

## Exporting CARTOREPLAY™ Module Data

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_export\_v7\_EN.xml

You can activate Timeline mode when a study is continued from Review mode.

By default, this option is only available within the first 18 hours after starting the study, because the data recorded by the CARTOREPLAY™ Module is not saved with the study. To ensure that CARTOREPLAY™ data is exported by the Study Archiver, select the Include CARTOREPLAY™ Module data option when saving the study. This option is available only when saving to USB, because of the large file size. Exporting can take longer than with standard export.

# Timeline Mode Interface

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_ReplayInterface\_v7\_EN.xml

In Timeline mode, acquisition in the Main Map Viewer is disabled. A separate Timeline acquisition toolbar appears in the Monitor Pane. The Timeline Toolbar includes a button for capturing induced signals/body surface patterns.

![replay_toolbar_v7.png](data:image/png;base64...)

Figure 3: Timeline Toolbar

The Event Panel appears in the lower part of the Monitor Pane. The system clock time is displayed in the Monitor Pane in HH:MM:SS format.

![continuous_vis_fullScreen_v7.png](data:image/png;base64...)

Figure 4: Timeline Mode Display

The signals in the Monitor Pane are frozen at the Reviewed Time. The Reviewed Time is marked by a vertical line called the Review Line. The Review Line is always positioned in the center of the Monitor Pane. The Review Line does not move when the Reviewed Time is changed. Instead, the time segment displayed in the Monitor Pane and Event Panel is adjusted to keep the Review Line in the center of the display.

![continuous_reviewLine.png](data:image/png;base64...)

Figure 5: Review Line

A scroll bar for time navigation appears under the Event Panel. Use the scroll bar to change the time of the Review Line. Scroll left to position the Review Line at an earlier point of the study, or scroll right to position the Review Line at a later point.

The Event toolbar appears at the bottom of the Event Panel. Click the event buttons to hide or show events of a specific type.

![continuous_visualization_events.png](data:image/png;base64...)

Figure 6: Event Panel

Visualization of catheters at the Reviewed Time is added to the map viewers. The Timeline Catheter visualization is the same as real-time visualization except for catheter color. The Timeline visualization of a force catheter includes the force vector.

![continuous_acqu_cathVis_v7.png](data:image/png;base64...)

Figure 7: Timeline and Real-time Catheter Visualizations

In Timeline mode, the Show Catheter option is disabled. If the option was active when entering Timeline mode, it is automatically restored on the return to Real-time mode.

## Selecting the Reviewed Time

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_selectReplayTime\_v4-3\_EN.xml

There are two options for entering Timeline mode:

* Current time: The Reviewed Time is the time you enter Timeline mode
* Last viewed time: The Reviewed Time is the time last displayed in Timeline mode

These options are set in the drop-down menu of the Timeline button.

![replay_button_list.png](data:image/png;base64...)

Figure 8: Timeline Button Options

If you change the Reviewed Time setting while in Timeline mode, the change does not affect the current display. It will be applied the next time you enter Timeline mode.

When you activate Timeline mode for the first time in the study, only the Current time setting is available. For subsequent entries into Timeline mode, you can choose the setting you prefer.

## Displaying Timeline Catheters

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_showCathVix\_v4-3\_EN.xml

You can show or hide Timeline catheter visualizations in the map viewers. The Show/hide Replay Catheters option in the map viewer right-click menu lists all catheters that were connected at any time during the study. By default, all the listed catheters are selected. Clear the selection to hide a catheter.

![replay_CatheterSettings_v7.png](data:image/png;base64...)

You can hide any catheter at the Reviewed Time except for the mapping and ablation catheters. If a Timeline catheter is hidden and you select a replay time when it was the mapping catheter or ablation catheter, the catheter is displayed. When the Reviewed Time changes so the catheter is no longer the mapping or ablation catheter, the catheter is hidden and its checkbox on the list is cleared.

Icons in the Timeline Catheters list indicate the show/hide settings.

By default, the Event Panel shows all the events that took place during the displayed time segment. To hide or show a type of event, click the event button on the event toolbar at the bottom of the event panel. (See [Figure 10: " Event Panel with Selected Point and Various Events"](#target9000002)). When an event type is hidden, its toolbar button is displayed in gray.

If you double-click an event in any viewer (Point List, Main Map Viewer, etc.), the event is selected in the Event Panel. The selected event is highlighted and positioned at the Review Line. Only one event can be selected at any time. When a VISITAG™ Site or ablation event is selected, its start time is at the Review Line. When a pacing event is selected, its end time is at the Review Line.

When an event with several instances is selected, arrows are displayed to the left and right of the Review Line. Click an arrow to jump to the previous or next instance of the event. You can also jump by pressing the keyboard left and right arrows. For the first and last instances of the event, the corresponding arrow is disabled.

If you double-click an event in the event panel, it is selected in the appropriate viewers. For example, double-clicking a point in the Event Panel automatically selects it in the map viewers and on the Point List. Double-clicking a VISITAG™ Site event in the Event Panel automatically selects the VISITAG™ Site in the Main Map Viewer and displays its data.

If you change the VISITAG™ Preferences, the system recalculates the VISITAG™ Sites and updates the Event Panel.

## Using Calipers

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_calipers\_v4-3\_EN.xml

* To add a time caliper when in Timeline mode, press ALT and drag horizontally in the Monitor pane.
* To add a voltage caliper when in Timeline mode, press CTRL + ALT and click a signal.

You can also add calipers by clicking ![Tool Icon.png](data:image/png;base64...) and selecting the caliper. By default, the time caliper spans 200 ms around the Review Line, and the voltage caliper spans from minimum to maximum signal amplitude.

You can add multiple instances of each caliper.

Moving to a different segment of the study (by scrolling or by event jumping) may push time calipers out of view but they stay in place. Moving back to the same segment of the study brings the time calipers back into view.

Calipers are deleted when you exit Timeline mode.

Right-click a caliper to remove it.

## Retroactive Point Acquisition

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_visualization\_acquisition\_v7\_EN.xml

In Timeline mode, you can acquire EA points at the Reviewed Time, either manually or using continuous acquisition.

When Timeline mode is active, the acquisition panel in the Main Map Viewer is disabled. The Timeline acquisition toolbar appears in the Monitor pane, displaying recorded point data from the mapping catheter at the Reviewed Time. The point data includes cycle length (CL), local activation time (LAT), voltage (Bi), impedance (Imp), and force (g).

To remove point data from the toolbar, click the blue arrow.

![replay_toolbar_v7.png](data:image/png;base64...)

Figure 11: Timeline Toolbar

The annotation of the retroactively acquired point is the closest annotation prior to the Reviewed Time. The retroactively acquired points are added to the active map and to the Point List. The acquisition time of a retroactively acquired point is the time of its reference annotation. To display the points in chronological order, sort the Point List by time.

To acquire points retroactively, click the manual acquisition button on the Timeline toolbar. Points are acquired with the mapping catheter that was active at the Reviewed Time. You cannot change the mapping catheter retroactively.

![replay_manual_v7.png](data:image/png;base64...)

Points cannot be acquired retroactively in the following situations:

* There was an error message affecting acquisition at the Reviewed Time.
* The reference annotation in the Active Map does not match the annotation at the Reviewed Time. To enable retroactive point acquisition, select an Active Map with the same annotation.

If points cannot be acquired, the Timeline acquisition button is disabled. A tool tip on the button describes the error.

![acquire_timeline_disabled_7.png](data:image/png;base64...)

Figure 12: Disabled Acquisition Button with Tool Tip Error Message

# Dual Monitor

https://bwiildita.sharepoint.com/sites/prod/Topics/dualMonitor\_Intro\_v4-3\_EN.xml

The **Dual Monitor** feature supports display of the CARTO™ 3 System Application on two monitors in the observation room, with two repeater monitors in the operating room.

You can use the dual monitor option to extend the display across two monitors for more convenient viewing.

Table 1: Dual Monitor Configuration Options

| Option | Description |
| --- | --- |
| 2 + 2 | Two monitors in observation room, two monitors in operating room |
| 2 + 1 | Two monitors in observation room, one monitor in operating room |

The basic configuration (one monitor in each room) is still available.

When two monitors are in use, two display options are available:

* Clone Mode: The display on both monitors is the same.
* Extended Mode: One monitor is defined as the Primary monitor, and the other is the Secondary monitor. The CARTO™ 3 System display extends across both monitors.

![DualMonitor_extendedMode.png](data:image/png;base64...)

Figure 13: Dual Monitor Extended Display Mode

In Extended Mode, some items can be displayed in either monitor, some are always displayed in both monitors, and some are only displayed in the primary monitor.

Table 2: Extended Mode Display Locations

| Monitor | Item |
| --- | --- |
| Primary | * Opening Screen buttons * Initial Setup Screens (except for Location Setup) * External utilities such as the Export Data Tool, Image Processing Package, and the Catheter Definition Tool |
| Both | * Error and alert messages * Warning popup messages * Location Setup screen * Stimulation routing indication |
| Either | * Fixed windows such as the Map Viewers, ECG Viewers, and Point List   At least one fixed window must be displayed in the secondary monitor.   * Floating windows such as the Preferences dialog box or Transparency dialog box |
