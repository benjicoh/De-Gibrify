## Overview and Algorithm Principles

https://bwiildita.sharepoint.com/sites/prod/Topics/LPM\_intro\_EN.xml

**Late Annotation Mapping (LAM)** provides an additional mapping criterion that uses a **Late Boundary** (LB) annotation line to separate the standard LAT Window of Interest (WOI) into an early part and a late part. This mapping criterion applies a dedicated annotation algorithm to identify and annotate the last recurring wavefront deflection occurring in the late part of the WOI (after the LB) as opposed to the current Wavefront annotation that identifies the strongest negative deflection on the Unipolar signal. An annotation placed to the right of the LB is considered a **Late Annotation**.

LAM provides three levels of algorithm sensitivity. The default sensitivity level is Normal. You can change the level to High or Highest. This can be adjusted either dynamically during point acquisition or retrospectively for selected points on the map.

### Late Annotation Mapping Algorithm

https://bwiildita.sharepoint.com/sites/prod/Topics/LAM\_algorithm\_EN.xml

The LAM algorithm ensures that late annotations are recurring by matching the late activity in the current beat to the previous beat, thus providing time stability to late acquired points. Both distal and proximal electrodes are evaluated for mapping annotation. The point's location is on the electrode from which the mapping annotation was identified.

When mapping with an ablation catheter, both mapping annotation evaluation and the point's location are based on the tip (distal) electrode only.

When using Late Annotation as the mapping method, the following logic is used for acquiring points on the map.

* The algorithm searches for a Late Annotation candidate starting from (and including) the right WOI border and moving left towards (and including) the Late Boundary. Candidates are based on negative unipolar deflection (‑dV/dt) which aligns with the deflection in the bipolar signal.
* When a candidate is found, the system checks whether an appropriate deflection exists at the same temporal position (within ± 10 ms) in one of the previous beats (-1 or -2).
* If the candidate has no temporal match in the previous beats, the search continues for more candidates until the Late Boundary is reached.
* If a valid candidate is found, it is considered a **Late Annotation**.
* If no Late Annotation is found, the algorithm searches for a Wavefront annotation in the remaining part of the WOI. The annotation is on the greatest unipolar negative deflection (maximum ‑dV/dt) which aligns with the deflection on the bipolar signal.

### Local Voltage Window of Interest

https://bwiildita.sharepoint.com/sites/prod/Topics/LAM\_localVWOI\_EN.xml

The System provides an option for determining a local Voltage Window of Interest (VWOI) instead of using the standard VWOI. The Local Voltage method automatically calculates a VWOI around each late annotation and only measures the voltage of the late annotation, instead of measuring the peak-to-peak value of all deflections within a fixed VWOI. When a LAM map is created, Local Voltage is selected by default. This method is applied to all points on the map.

To use the standard fixed VWOI, clear the Local Voltage check box.

When the Local Voltage checkbox is selected, the system behaves as follows:

* If a Late Annotation is found, a local VWOI is automatically calculated around the Late Annotation and the voltage value is measured within that local VWOI.
* If no Late Annotation was found for that point the voltage is measured within the full span of the WOI.

For no-LAT points, the voltage value appears in the Point List; however, the point is gray in the voltage maps (unipolar and bipolar).

To calculate borders of the Local VWOI, the LAM algorithm searches for a 10 ms **quiet segment** (low signal) on each side of the late annotation, starting 10 ms from the Late Annotation. The search for **quiet segments** is limited by the standard LAT WOI and a 60 ms time interval in either direction. If no quiet segment is found, the local VWOI border is set to +/-20 ms from the annotation.

Voltage values are measured within that Local VWOI (see [Figure 5: "Selected Point Viewer - Local Voltage Window of Interest"](#target9000001)).

Local Voltage selection is indicated on the voltage color scale bar when a voltage map type is displayed in the map viewers.

### LAM and Point List

https://bwiildita.sharepoint.com/sites/prod/Topics/LAM\_pointList\_EN.xml

With the addition of Late Annotation Mapping, the Point List has additional columns when a map is a LAM map. The column with the heading Late shows purple dots for points annotated after the Late Boundary.

The Late Sens. column indicates the LAM sensitivity value for each point. If a different sensitivity is chosen for a selection of points, either during mapping or retroactively, the Sensitivity Level indicated in this column reflects that change.

These two additional columns are added by default to the Point List whenever the Late Annotation mapping criterion is chosen for a map.
