# Pace Mapping Software (PASO™) Module Overview

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_workingWith\_c3\_v3\_EN.xml

**The Pace Mapping Software (PASO™) Module** (PASO™ Module) can be used for correlating 12-lead ECG captured during the patient's induced or spontaneous arrhythmia to other induced signals (IS) or to the signal captured while pace mapping. While induced arrhythmia signals are not associated with any point or map, the pace-mapped signal (PM) is always associated with an electroanatomical point. The System calculates a correlation index that helps to compare between pace mapped points and between different induced signals. You can use the automatically-assigned best match or choose your own.[[1]](#footnote-1)

## Interactions between the PASO™ Module and the CONFIDENSE™ Module

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_interactions\_pattern\_7p3\_EN.xml

In general, the Pattern Matching filter in the CONFIDENSE™ Module[[2]](#footnote-2) functions independently from the PASO™ Module. However, if both modules are installed, a captured signal/pattern appears in both the pattern bank and the IS List.

* The pattern in the pattern bank and the signal in the IS List will have the same number, but different prefixes. For example, the third capture will become BS PTRN 3 and IS 3.
* Numbering is global and cannot be edited.
* The global number increases by 1 each time a signal/pattern is captured.
* The global number increases by 1 any time a signal/pattern is duplicated/copied in either the pattern bank or the IS List. However, a copied IS signal does not appear in the pattern bank and a copied pattern does not appear in the IS List.
* The global number does not change if a signal is deleted from either list.
* Once the signal and pattern appear in their respective banks, they are independent. For example, edits to BS PTRN 3 do not affect IS 3.
* Captures during the setup phase (before moving to the Mapping phase) appear only in the IS List. For example, if there are 3 captures during setup and then one when mapping starts, the IS List has 4 signals, but the pattern list has only 1 signal: BS PTRN 4.

The morphology of interest (MOI) may be different in the two modules. Within the PASO™ Module, the MOI for the first IS in the PASO™ Module is centered on the first peak of the last 2.5 seconds of Lead II. For each additional IS, the MOI is based on correlation with the existing IS references. In the CONFIDENSE™ Module, the pattern of interest (POI) is set at a fixed width of ± 150 ms around the last annotation of the recorded signal.

Risk analysis

The two modules use different methods to calculate correlation. Therefore, the same data can yield different results in each module.

## Induced Signals

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_induced\_signals\_c3\_v4\_EN.xml

|  |  |
| --- | --- |
| ![DxNoteGeneric.png](data:image/png;base64...) | NOTE  A focal ablation catheter does not have to be connected in order to acquire induced signals (IS). |

Induced or spontaneous signals can be captured at any point after completion of the Study Setup screen. During the Setup phase, the PASO™ Viewer opens in the Setup Help pane. You can hide the PASO™ Viewer to review the Setup Help.

For each captured IS, 62.5 seconds for all body surface leads are recorded:

* 2.5 seconds after acquisition are used for correlation calculation
* 60 seconds before acquisition serve as an ECG buffer

The following IS information is saved with each study:

* Name
* Reference IS status
* Median cycle length (CL) as calculated on the Lead II signal
* Time the signal was recorded
* 62.5 seconds of recorded signals for all body surface leads

Each IS recording is available for all the maps in the current study.

## Morphology of Interest

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_MOI\_c3\_v4\_EN.xml

After recording an IS, the PASO™ Module automatically sets the morphology of interest (MOI) at a fixed width of ± 150 ms. For the first IS, the MOI is set around the first peak of the last 2.5 seconds of the Lead II channel. If the first peak on the leading channel is less than 150 ms from the beginning of the data recording, the second peak is used.

For each additional IS, the system sets the MOI where the best correlation within the last 2.5 seconds, calculated with existing IS references, was indicated.

The MOI is used when calculating correlation with other signals (both IS and PM). If the MOI does not fully enclose the signal of interest of the arrhythmia, you can edit the MOI. You can scroll back up to 60 seconds so as to select the desired complex.

## Reference IS

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_referenceIS\_c3\_v6\_EN.xml

If an IS has a unique morphology it is designated a Reference IS. Only Reference ISs are used for comparison with PM signals.

The first IS you record is marked as a Reference IS by default. Each time you record a new IS, it is compared to every Reference IS in the study, according to the correlation parameters.

* If the new IS differs significantly from every Reference IS (low correlation value), it is designated as a Reference IS.
* If the new IS corresponds to a Reference IS (high correlation value), the IS remains in the list of available signals, but it is not used in IS or PM correlation calculations.

You can change the Reference IS designation manually.

Select or clear the check box in the Acquisition tab of the PASO™ Viewer.

![ReferenceIS_Checkbox_v6.png](data:image/png;base64...)

Figure 2: Reference IS Designation

If an IS contains more than one MOI, you can create a copy of the IS. Each version can be designated as a Reference IS, with a different MOI.

## PM Signals

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_pm\_signals\_c3\_v4-1\_EN.xml

When a PM is captured, 10 seconds are recorded for all body surface leads:

* 2.5 seconds after acquisition
* 7.5 seconds before acquisition

To view the full 10-second PM history, set the Correlation field to None.

An active interval of 2.5 seconds is used for calculating correlation. By default, the active interval is the last 2.5 seconds of the PM; however, you can move the active interval to any part of the captured signal.

Pace mapped (PM) signals are always associated with a selected point in a CARTO™ 3 Map. If no point is selected, the PM will be associated with the last acquired point. If a point group is selected (Group Selection mode), the PM will be associated with the Active Point.

Each point can have only one associated PM.

## Comparing IS and PM Signals

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_IS-PM\_signals\_compare\_c3\_v4\_EN.xml

Each PM is automatically compared to each reference IS, to find the signal set with the highest correlation. A PM signal is considered Matched only if the level of correlation is equal to or greater than the threshold values entered in the PASO™ Preferences.

The correlation can be viewed in the PASO™ Viewer, the Point List, and the Correlation Map.

During the procedure, if a new reference IS with a closer correlation to mapped PM signals is acquired, the system automatically updates the information for the relevant points.

For any PM, the matched Reference IS having the highest correlation value is considered the best IS and is associated with that PM. A Reference IS can be associated with more than one PM.

You can manually change the Reference IS that is associated with the PM (Current IS) to another Matched Reference IS. Subsequent matched ISs will not override the user designation.

|  |  |
| --- | --- |
| ![DxNoteGeneric.png](data:image/png;base64...) | NOTE   * Noisy BS signals might result in misleading automatic association. In this case, check the associated signals for accuracy. * When correlation between IS and PM is calculated, the System takes into account everything that is within the MOI. If the pacing spike is within the MOI, correlation value is reduced.   To ensure accurate correlation calculation, adjust the MOI so that it does not include the pacing spike. |

You can export the correlation values to a text file.

### Lead Correlation Value

https://bwiildita.sharepoint.com/sites/prod/Topics/Lead Correlation Value\_EN.xml

When comparing two sets of signals, the PASO™ module provides the correlation value of each lead in one signal set with the corresponding lead in the other set. This comparison either relates an IS to another IS, or a PM to an IS.

The average correlation is calculated by summing these values and dividing the sum by the number of leads (12). Removing leads from the PASO™ Viewer does not remove them from the correlation calculation.

## Copying, Moving, and Deleting Points with PM Signals

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_copyMoveDelete\_v3\_EN.xml

When a point is copied to another map, the PM signal is also copied, and associated with the copied point.

When a point is moved to another map, the PM signal remains associated with the point.

When a point is deleted and placed in the Recycle Bin, the associated PM signal is removed from the PASO™ Viewer.

If the point is restored from the Recycle Bin, the PM signal is restored as well.

# General Workflow

https://bwiildita.sharepoint.com/sites/prod/Topics/paso\_generalWorkflow\_c3\_v4\_EN.xml

The PASO™ Module workflow is divided into the following general phases:

|  |  |
| --- | --- |
| Preferences | Set the correlation threshold parameters. It is recommended to set the preferences before capturing signals. Preferences can be saved in a user-defined template. |
| IS Capture | BS-ECG signals representing the patient's arrhythmia are recorded. If necessary, the arrhythmia can be induced.  Induced signals can be recorded in the Setup phase of the Study, as soon as the Study Setup screen is completed and all the BS-ECG patches have been attached to the patient and connected.  Each unique morphology has a designated Reference IS. |
| Pace Mapping | A pace mapped signal (PM) is associated with a selected point in a CARTO™ 3 Map. PMs can be recorded during the Mapping phase, when there is at least one IS and one electroanatomical point.  The recorded PM is automatically compared to each Reference IS, to find the signal set with the highest correlation. |
| Comparison | PASO™ Tools such as the PASO™ Viewer and the **Correlation Map** display correlation numerically and visually. |

You can record an IS after recording a PM signal, and you can switch between the Acquisition tab and the Comparison tab at any time after completing the Setup phase.

You can print signals and export correlation data from the Study menu.
