# CARTO SMARTTOUCH™ Module Overview

https://bwiildita.sharepoint.com/sites/prod/Topics/Smarttouch\_Overview\_EN.xml

**The CARTO SMARTTOUCH™ Module** enables the CARTO™ 3 System to display the magnitude and direction of the force applied to intracardiac tissues when used with a compatible force catheter. The CARTO™ 3 System displays the force data in real time. It also records the data for review.[[1]](#footnote-1)

When the CARTO SMARTTOUCH™ Module is installed, the CARTO™ 3 System can display force readings when a compatible force catheter is connected.

For accurate force measurement, all four tip electrodes must be outside the sheath. If the electrodes are covered, the Dashboard displays **SH**.

Before force readings can be displayed, it is necessary to zero the force reading.[[2]](#footnote-2) Perform this zeroing when the following conditions are met:

* The catheter is within chamber of interest
* No force is applied on the catheter tip
* No other catheter is in close proximity

In some instances, it may also be necessary to zero the force reading during the procedure.

After zeroing, the user can set a force range with upper and lower force thresholds. These thresholds are used in the following ways:

* Display of force magnitude includes indication of whether the force is below, within, or above the thresholds.
* The percentage of force which is above the lower threshold during a user-defined time interval can be displayed.
* During FAM data acquisition, it is possible to block acquisition of volume if the force is above the upper threshold.

An optional maximum force threshold can be set. If the force reading is over this threshold, the Main Map Viewer background will flash.

## Compatible Catheters

https://bwiildita.sharepoint.com/sites/prod/Topics/smartTouch\_catheter\_about\_EN.xml

Catheters with CARTO SMARTTOUCH™ Catheter Technology (referred to as force catheters) contain an embedded force sensor, which collects data about the force magnitude and the angle of the force between the catheter tip and the intracardiac tissue. As with other mapping catheters, the force catheter contains a magnetic sensor in its tip that continuously collects location data as the catheter is moved inside the heart.

Consult your Biosense Webster representative regarding the availability of compatible force catheters in your country. For more information about using these catheters, refer to the *Instructions for Use* of the catheter.
