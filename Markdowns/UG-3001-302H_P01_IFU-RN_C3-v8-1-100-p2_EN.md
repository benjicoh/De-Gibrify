# Overview

The CARTO™ 3 System V8.1.100 with PFA Support OMNYPULSE™ Catheter enables CARTO™ 3 System procedures including visualization, mapping, and Pulsed Field Ablation (PFA) when using an OMNYPULSE™ Catheter and a compatible version of the TRUPULSE™ Generator.

## About this Release

The CARTO™ 3 System V8.1.100 enables the physician to map both the anatomy and electrical conduction from the heart, supplying all the information the physician needs, allowing focused PFA without data interpretation deficiencies.

This version is based on CARTO™ 3 System V8.1.0.303 and supports PFA using the OMNYPULSE™ Catheter.

The software is compatible with the SMARTABLATE™ RF Generator and with the Clinical TRUPULSE™ Generator (Monitor Firmware v2.0.0.98) and supports a Multi-generator (MultiGen) connection where both generators can be simultaneously connected to the CARTO™ 3 Workstation.

CARTO™ 3 System V8.1.100 also supports the use of nGEN™ RF Generators, but not as part of a MultiGen connection. See [" Connections"](#target9000001).

**Unsupported Catheters**

* LASSOSTAR™ NAV Catheter
* QDOT MICRO™ Catheter
* VARIPULSE™ Catheter
* NUVISION™ NAV Ultrasound Catheter[[1]](#footnote-2)

**Unsupported Features**

* CARTOSOUND™ 4D Module.
* VISITAG™ TPI Filter disabled by default (VARIPULSE™ feature pack dependency).
* Commercial generator version not supported (clinical version only).
* TRUPULSE™ Generator Status Window.
* Multi-generator (MultiGen) support for simultaneous TRUPULSE™ and nGEN™ generator connections.

## Functional Principles of PFA

PFA for cardiac applications employs high voltage and very short duration pulses (PF energy), by a dedicated generator (TRUPULSE™), which results in destabilization of the cellular membranes, creating pores (electroporation) and ultimately leading to cell death.

Myocardial tissue has a low pulsed electric field energy threshold for irreversible electroporation, relative to neighboring cell types. Red blood cells, vascular muscle, endothelium, and nerves have higher electric field thresholds, thereby limiting the potential for collateral damage when pulsed electric field energy is delivered intracardially.

This CARTO™ 3 System software version supports the TRUPULSE™ Generator. The TRUPULSE™ Generator is a specialized device that delivers pulsed electrical energy which, when used with a compatible catheter, produces electric fields intended to ablate intracardiac tissue, resulting in PFA.

## Indications For Use

The intended use of the CARTO™ 3 System is catheter-based cardiac electrophysiological (EP) procedures. The CARTO™ 3 System provides information about the electrical activity of the heart and about catheter location during the procedure. The system can be used on patients who are eligible for a conventional electrophysiological procedure.

The system has no specific contraindications.

## TRUPULSE™ Generator

The CARTO™ 3 System receives the following ablation session data from the TRUPULSE™ Generator:

* OMNYPULSE™ Catheter electrodes for ablation (automatically selected by the generator).
* Session number.
* Session parameters (number of applications per session, delays between applications in the session, current active application in the session).
* Number of completed applications.
* Application completion percentage.

Session data received from the TRUPULSE™ Generator is displayed in these messages:

* Status message - Identification as PF Generator, electrodes selected for ablation.
* Application start message - Ablation session number.
* Application stop message - Application completion percentage.
* Ablation start message - Session parameters.
* Ablation stop message.

For information on connecting the TRUPULSE™ Generator to the CARTO™ 3 System, refer to the TRUPULSE™ Generator *Instructions for Use*.

## Potential Adverse Events

A number of serious adverse reactions have been documented for catheter ablation procedures including pulmonary embolism, myocardial infarction, stroke, cardiac tamponade, and death. The following complications were also noted to have occurred during the Study or have been reported in the literature:

* **Catheterization/catheter procedure related:** Vascular bleeding/local hematomas, thrombosis, AV fistula, pseudoaneurysm, thromboembolism and vasovagal reactions, cardiac perforation, tamponade, thrombi, air embolism, arrhythmias and valvular damage, pneumothorax and hemothorax.
* **PFA related:** Chest pain/discomfort, ventricular tachyarrhythmia, transient ischemic attack (TIA), cerebrovascular accident (CVA), complete heart block, coronary artery spasm, coronary artery thrombosis, coronary artery dissection, cardiac thromboembolism, pericarditis, cardiac perforation/tamponade, valvular damage, hemolysis, acute renal failure, and increased phosphokinase level.

# Connections

This version of the CARTO™ 3 System supports three generator configurations:

* TRUPULSE™ Generator only.
* RF generator only (nGEN™ or SMARTABLATE™). Refer to the documentation provided with the generator.
* Simultaneous connection of a TRUPULSE™ Generator and a SMARTABLATE™ Generator. In this MultiGen configuration, only one generator is connected to the PIU, but both generators are connected to the CARTO™ Workstation. The active generator is selected in the Tools menu. The default setting is TRUPULSE™.

The generators can be switched without exiting the study. See ["MultiGen Support"](#target9000002).

* If the CARTO™ System does not detect a connection with a supported generator, this is indicated in the System Status Window.

This version supports the use of an nGEN™ RF Generator as a ***standalone*** generator only. MultiGen configuration with the nGEN™ RF Generator is not supported.

### Setup When Starting with PFA

Workstation: Connect both generators to the CARTO™ 3 Workstation (see ["MultiGen Connections"](#target9000006)).

* **PIU**: Connect the TRUPULSE™ Generator from the CARTO™ 3 System socket on the CIU of the generator to the 20 POLE A socket on the PIU.
* **OMNYPULSE™ Catheter**: Using an extender cable, connect the OMNYPULSE™ Catheter to the W cable. Two of the W cable connections are connected to Therapeutic sockets A + B on the generator CIU. The third W cable connection is attached to a Tx eco Cable - which connects to the PIU MAP socket.

When you begin the study, both connected generators are displayed in the Connected Machines section of the Study Setup screen.

### Switching from PFA to RFA During a Study

It is possible to switch from the TRUPULSE™ Generator to the RF generator during a study.

For generator connections, refer to the *Instructions for Use* provided with the generator.

1. In the Tools menu, switch the generator.

Tools > Generators > SMARTABLATE™[[2]](#footnote-3)

A message appears, prompting you to disconnect the TRUPULSE™ Generator.

![PFA_8-1-100_Switching_PFA_to_RF_During_Study.png](data:image/png;base64...)

1. Disconnect the TRUPULSE™ Generator from the 20 POLE A socket of the PIU.
2. Disconnect the OMNYPULSE™ Catheter - remove the *Tx eco Cable* from the MAP socket of the PIU.
3. Connect the RF generator to the RF Generator socket of the PIU.
4. Connect ablating RF catheter to the PIU.
5. After verifying that the TRUPULSE™ cable is disconnected from the PIU, click I Approve.

### Switching from RFA to PFA During a Study

It is possible to switch from the RF generator to the TRUPULSE™ Generator during a study.

For generator connections, refer to the *Instructions for Use* provided with the generator.

1. In the Tools menu, switch the generator.

Tools > Generators > TRUPULSE™

A message appears, prompting you to disconnect the RF Generator.

![PFA_8-1-100_Switching_RF_to_PFA_During_Study.png](data:image/png;base64...)

1. Disconnect the RF Generator from the RF socket of the PIU.
2. Disconnect the ablating catheter.
3. Connect the TRUPULSE™ Generator to the 20 POLE A socket of the PIU.
4. Connect the OMNYPULSE™ Catheter and TRUPULSE™ Generator to the PIU with a W-adaptor Cable and Tx eco Cable to the MAP socket of the PIU. See ["Connecting the Catheter to the PIU"](#target9000007).
5. After verifying that the RF Generator cable is disconnected from the PIU, click I Approve.

The CARTO™ 3 System now resets the visualization matrix. During this time, the Reset Visualization progress indication appears on the status bar. If use of ACL catheters is needed, the visualization matrix needs to be rebuilt.

### PF Tag Positioning Method

PF Tag Positioning method for PFA can be found in the CARTO™ 3 System Tools menu.

![PFA_8-1-100_PF_Algorithms.png](data:image/png;base64...)

Figure 14: PF Tag Positioning method

There are two site positioning methods that can be used for PFA sessions:

1. Stability+ (selected by default).
2. First application location.

See Stability and Filter Indications on the ["Readings Dashboard"](#target9000013).

When Stability+ is selected, the CARTO™ 3 System continuously analyzes the overall movement of the catheter, separating the movement due to respiration from the actual catheter movement. This continuous analysis reduces the time for initial indication of stability and the appearance of PF VISITAG™ Sites. This filter can be used instead of the Gated (ACCURESP™) algorithm, which depends on ACCURESP™ Respiration Gating Training. This algorithm supports all focal ablation types including short duration sessions.

**Considerations when using Stability+**:

* The algorithm requires a training period. This happens automatically in the background either during or after the catheter visualization process while a magnetic sensor-based catheter is in the mapping zone. If a focal ablation catheter is connected while the training is in process, an alert message is displayed until the training period is finished.
* This algorithm measures the distance from the center of the site to the center of the basket. If the catheter moves beyond a distance of 3 mm or moves faster than 2.5mm/sec, the site breaks. If a site breaks during ablation due to instability, and Show Site Break Indication is enabled (see ["PF Site Tag Preferences"](#target9000014)), a halo is displayed for up to 3 seconds around the broken site tag. This indication disappears at the end of the ablation session or when a new site appears.
* For faster tag appearance, ensure catheter stability before starting ablation.
* For optimal algorithm indication, use point by point ablation sessions.
* In the Gated (ACCURESP™) stability algorithm, the maximum distance is based on the standard deviation, whereas in the new Stability+ algorithm, the maximum distance change is 3 mm. This makes Stability+ more sensitive to movement.
* If switching between algorithms during a study, the CARTO™ 3 System recalculates and presents the PF VISITAG™ Sites according to the current algorithm.

REP17406 D-1.27 D-1.28 D-1.60

Site breaks may occur when the catheter is moved unintentionally. Since the ablation session is limited by the generator (maximum of 12 applications), once a site break occurs, the ablation session number of applications is *not* reset. For example, if a site break occurred after 6 out of 12 applications, the new site is able to obtain at most 6 applications at the new position. This might have implications for the following features:

* PF Index - The new tag might not reach the target PF index, and additional ablations might be required.
* Site stability - The set filters do not cross the filter threshold, and a tag is not created at the new position (not relevant for First application location as the CARTO™ 3 System automatically creates one PF VISITAG™ Site for each ablation session. The PF VISITAG™ Site is based on the initial position of the DE STSF Catheter in the first application in the ablation session).

Pay close attention to the PFA progression bar, and number of applications on the Readings Dashboard.

REP17406 A-1.19

If Stability+ cannot receive required data (for example, due to metal interference or the catheter not being in the mapping zone), the algorithm becomes unavailable. and an alert appears. Once the issue is resolved, the algorithm performs a soft reset, which takes up to 20 seconds, and an animation appears in the Readings Dashboard for both Stability+ and Tag Index. . During this reset, PF VISITAG™ Sites might not be created, or they might not contain all of the ablation data. Tag Index values might not be accurate. The alert disappears when the algorithm is available again.

REP17406 D-1.23

In very rare situations, Stability+ may not detect the stability segment. As a result, a PF VISITAG™ Site will not appear. For example, this might occur if a patch becomes disconnected or if the catheter is out of the mapping zone. During a PFA session, monitor data such as catheter location, Graphs Viewer, and Readings Dashboard. Ablation termination decisions should not be based on whether a PF VISITAG™ Site appears.

REP17406 A-1.18

In very rare situations, the Stability+ may falsely split the PF VISITAG™ Site in a manner which does not reflect the catheter stability during ablation. As a result, two PF VISITAG™ Sites will appear instead of one. Ablation-related decisions should be based on clinical judgement.

# Study Reviews, Backup and Restore

* The backup and restoration of all PF catheter ablation data is supported - with the exception of recalculated Site Stability related data.
* Study restore for the following versions is supported: 7.9.1.286 (no support for Stability+ data), 7.9.2.240 (no support for Stability+ data), V8.1.0.325 (supports Stability+ data for RF only), and V8.1.100.128 (supports Stability+ data for RF and PF) . There is no support for study restore of data from versions containing different service packs (OMNYPULSE™/DE STSF).
* This version supports backing up and review of both Coloring Method and Coloring Thresholds.
* When restoring a study performed with PF Index on a system that doesn't support it, PF Tags are displayed with the default PF Completion coloring method.
