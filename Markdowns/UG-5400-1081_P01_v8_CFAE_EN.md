# About the CARTO™ CFAE Module

https://bwiildita.sharepoint.com/sites/prod/Topics/About\_CFAE\_6\_EN.xml

|  |  |
| --- | --- |

The information herein supersedes all differences between translations or text in the CARTO™ 3 System documentation. This document assumes that you are familiar with, and have on hand, the instructions provided with your system.  Images in this document are for illustrative purposes only. |

The **CARTO™ CFAE Module** enables detection of Complex Fractionated Atrial Electrograms (CFAE) on IC electrograms, based on user-defined parameters.

While you cannot precisely determine how many CFAE complexes occur, based on your definition of a CFAE complex, the system identifies the number of intervals between adjacent CFAE complexes, and the cycle length of these intervals. In this way, you can estimate the number of CFAE complexes within certain amplitude and duration values. These values are defined via the options in the CFAE tab of the Preferences dialog box.

When viewed, the additional data is displayed in new columns in the Point List. In addition, parameters relating to complex duration and the maximum and minimum thresholds are displayed with signals in the Selected Point Viewer.

This module is based on the CARTO™ 3 System Software, including impedance mapping and the CARTOMERGE™ Image Integration Module. For full information on working with the CARTO™ 3 System, refer to the ***Instructions for Use*** and documentation provided with the CARTO™ 3 System.

## Displaying a CFAE Map

https://bwiildita.sharepoint.com/sites/prod/Topics/display\_CFAE\_map\_C3\_EN.xml

CFAE maps are displayed according to values for specific CFAE parameters.

CFAE maps can be displayed in the Main Map Viewer or the Additional Map Viewer.

|  |  |
| --- | --- |
| 1. | Right-click the map in the map viewer or Map List. |
| 2. | Select the required map type. |

The display is updated according to your selection. For example, if you select CFAE Shortest Complex Interval (SCI), the map is colored according to the shortest complex interval (the shortest interval between identified repeated complexes) for each acquired point. The color scale bar indicates the maximum and minimum durations [ms] detected (purple to red, respectively).

## CFAE Preferences

https://bwiildita.sharepoint.com/sites/prod/Topics/CFAE\_preferences\_6p5\_EN.xml

The CFAE tab of the Preferences dialog box (Tools > Preferences) is used to set CFAE parameter and display values.

![CFAE_setup_db_c3_v7.png](data:image/png;base64...)

Figure 1: CFAE Tab of Preferences Dialog Box

A CFAE complex is defined by the System based on the intervals between peaks. These values are applied to all the maps in the study, and are saved together with the map. You define the thresholds [mV], as well as the interval [ms] between peaks.

Use the Display parameters to define the elements that are displayed in the map viewers and the Selected Point Viewer.

The preferences, with the exception of Confidence Level, can be saved to a template.

| Option | Description |
| --- | --- |
| Threshold Values | Minimum and maximum values, in millivolts  These values set the minimum and maximum amplitude thresholds above and below the axis.  The system checks the 2.5 s recording for each point and identifies peaks that are between or above these thresholds Only peaks that are above the minimum and below the maximum thresholds are used in CFAE calculations. Peaks beyond the maximum threshold are also marked in the Selected Point Viewer, although they are not used in the CFAE calculations. (See ["Using the Selected Point Viewer"](#target9000004)). |
| Duration Values | Minimum and maximum values, in milliseconds, which define the interval of interest  After the System identifies peaks within the amplitude threshold, the interval between these peaks is evaluated. If the interval between adjacent peaks is within the defined range, it is included in CARTO™ CFAE Module calculations and display options. |
| CFAE Tag Size | Adjust the size of the tag displayed on the map |
| Confidence Level | Sets the High and Low confidence parameter values. The confidence level is defined by the number of intervals measured during the 2.5 second recording for each point.  To toggle the display of the number of intervals, right-click the map and select Show Labels. |
| Thresholds lines | When selected, displays colored bars marking the minimum and maximum thresholds for peaks in the Selected Point Viewer. The minimum threshold is represented by an orange bar and the maximum threshold is represented by a blue bar. |
| Peaks | When selected, places white dots on detected peaks within the thresholds, and purple dots on peaks outside the thresholds (Selected Point Viewer). |

|  |  |

| ![DxNoteGeneric.png](data:image/png;base64...) | NOTE  You can use the up and down arrow keys on the keyboard to adjust the Duration Values, Threshold Values, and Confidence Level. |

## Displaying CFAE Tags

https://bwiildita.sharepoint.com/sites/prod/Topics/Displaying Confidence Level Tags\_4-3\_EN.xml

CFAE Tags can be applied to indicate the interval confidence level (ICL) for all points (see [Figure 4: "Map with CFAE Tags and Labels Displayed"](#target9000007)). These tags can be displayed in all types of maps.

A legend with the confidence level tag definitions is displayed below the Map List whenever confidence level tags are enabled.

![CFAE_ConfidenceTags_legend_v4.png](data:image/png;base64...)

Figure 3: Confidence Level Legend

To show or hide the tags, right-click the map and do one of the following:

* Select CFAE Tags to apply confidence level tags in the map according to the Display values set in the Preferences dialog box.
* Select Show Labels to show the number of intervals at each tagged point. This option is only available when confidence level tags are displayed.
* Clear Show Labels to remove the labels.
* Clear CFAE Tags to remove both confidence level tags and labels.

The Display values in the Preferences dialog box affect the color of confidence level tags as follows:

* **High**: A red tag is applied to points that have more than the number of intervals entered in the High parameter field.
* **Medium**: A blue tag is applied to points that have a number of intervals equal to or between the High and Low parameter field.
* **Low**: No tag is applied to points that have less than the number of intervals entered in the Low parameter field.

## Viewing CFAE Point Data in the Point List

https://bwiildita.sharepoint.com/sites/prod/Topics/CFAE\_Data\_PointList\_C3\_EN.xml

When a CFAE map is displayed, new data is displayed in one or two columns of the Point List, as follows:

* **ICL (Interval Confidence Level):** Always displayed. If there are two or more adjacent CFAE complexes in the signal, the ICL column displays the number of CFAE intervals.
* **SCI (Shortest Complex Interval):** Displayed when map type is SCI. Displays the value of the shortest interval between two consecutive CFAEs in the signal.
* **ACI (Average Complex Interval):** Displayed when map type is ACI. Displays the average interval between the CFAE complexes.
