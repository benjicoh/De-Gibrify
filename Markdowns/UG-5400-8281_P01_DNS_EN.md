# CONFIDENSE™ Module Overview

https://bwiildita.sharepoint.com/sites/prod/Topics/confidentMapping\_overview\_UG\_EN.xml

The **CONFIDENSE™ Module** is a collection of features that aid in the acquisition and understanding of CARTO™ 3 Maps. [[1]](#footnote-1)

|  |  |
| --- | --- |
| Continuous Mapping | The **Continuous Mapping Feature** enables continuous acquisition of EA points which meet a set of pre-defined filters. |
| Tissue Proximity Indication | With **Tissue Proximity Technology**, the CARTO™ 3 System uses impedance measurements to determine an electrode's proximity to cardiac tissue. If the electrode is in the proximity of the tissue, the electrode is considered to be touching. |
| Wavefront Mapping Annotation | The **Wavefront Mapping Annotation** uses an algorithm to search for the greatest negative deflection (‑dV/dt) in each distal unipolar signal and mark it for the local activation time calculation. |
| Map Consistency | The **Map Consistency Display** is a point filter that identifies points whose Local Activation Time (LAT) values are not consistent with the LAT values of neighboring points. When this filter is applied, the CARTO™ 3 System marks these outliers. LAT outlier points do not contribute to LAT map coloring. |
| Ripple Maps | A **Ripple Map** is a dynamic display of bipolar electrogram data in an electroanatomical map. At each point, the corresponding bipolar electrogram is dynamically displayed as a bar perpendicular to the map surface. |

# Continuous Mapping

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_acquisition\_intro\_v6-3\_EN.xml

The **Continuous Mapping Feature** enables continuous acquisition of EA points which meet a set of pre-defined filters.

You must set the filters and their thresholds before mapping. After you activate Continuous Mapping, the CARTO™ 3 System continuously acquires points each time all the pre-defined filters are met on each reference annotation. Acquisition continues until you stop it. Points can be manually acquired during Continuous Mapping.

| --- | --- |

## Continuous Mapping Filters

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_acquisition\_preferences\_v6p5\_EN.xml

When electroanatomical points are acquired, they are evaluated according to a set of pre-defined filters. Points are accepted only if they pass all the selected filters.

Filters are set in the Acquisition Filters tab of the Preferences dialog box. Each map has its own settings. The name of the current map is displayed in the Acquisition Filters tab of the Preferences dialog box.

![AcquisitionFilter.png](data:image/png;base64...)

Figure 1: Acquisition Filters Tab

Table 1: Map Related Filters for Continuous Mapping

| Filter | Description |
| --- | --- |
| Cycle Length | Activates the selected cycle length filter (Stability or Range).   * Range: A point can be acquired only if the cycle length is within the defined range. * Stability: A point can be acquired if the difference (%) between the current cycle length and the median cycle length of all relevant points in the current map is less than the selected threshold.   Floating points, location-only points, and points in the Recycle Bin are not included in the calculation. |
| Pattern Matching | The Pattern Matching option is not available if there are no captured patterns.  See ["Continuous Mapping with Pattern Matching"](#target9000001). |
| Position Stability | A point can be acquired if the location stability between consecutive beats is less than or equal to the threshold. |
| LAT Stability | A point can be acquired if the LAT difference between consecutive beats is less than or equal to the threshold.  Consecutive points with no LAT value are considered to be stable. |
| Force | REP4611 D-V3-1.3.1.15  A point can be acquired according to the force reading. Select either Above Minimum Threshold (equal to or greater than the minimum force threshold) or Within Thresholds (between the minimum and maximum thresholds).  Available only when the mapping catheter is a force catheter.[[2]](#footnote-2) |
| Do Not Acquire While Pacing | If selected, points are not acquired during stimulation.  Applies only to catheters connected to the PIU. |
| Density | REP4611 A-V6-1.10.1  A point can be acquired only if it is at least this far from all existing points.  The first point acquired in a region defines the center of a sphere. No other points can be acquired within that sphere, unless the first point has no LAT value. In this case, the first point with a LAT value is also acquired. |

You can change the Continuous Mapping settings during acquisition. Changes take effect after you click Apply or OK.

The System Filters apply for both Continuous Mapping and manual acquisition.

Table 2: System Filters

| Filter | Description |
| --- | --- |
| Tissue Proximity | A point can be acquired if it is in close proximity to the tissue.  Available only for mapping catheters which support Tissue Proximity Indication (TPI) |
| Respiration Gated | A point can be acquired only if it is within the respiratory gating threshold. |

Points acquired in this mode are the same as manually-acquired EA points. Points are acquired to the Active Map. If you change the Active Map, acquisition stops.

During Continuous Mapping, the last acquired point or point group is not automatically selected in the Point List, the Selected Point Viewer, or the map. The Beat Buffer is not available for automatically acquired points.

If the Point List is sorted by anything other than index number, the sorting is not updated until Continuous Mapping stops. An icon appears by the column to indicate that sorting is not up to date. The list is sorted automatically when Continuous Mapping stops.

![pointList_notSorted_CL.png](data:image/png;base64...)

Figure 2: Point List During Continuous Mapping, Sorted by Cycle Length

Continuous Mapping is not available in the following situations:

* Application of energy for ablation is detected
* Respiration gating training is required (if filter is active)
* The number of points in the map or the study is near the limit
* CFAE is active (CARTO™ CFAE Module)
* Replay mode is active (CARTOREPLAY™ Module)

If a System error message appears during acquisition, the system will reject points for 5 seconds without disabling the Continuous Mapping icon. If the problem persists for more than 5 seconds, acquisition stops and the icon is not available.

## Continuous Mapping with Pattern Matching

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_patternMatch\_intro\_7p3\_EN.xml

The Pattern Matching filter is an optional Continuous Mapping filter. It allows acquiring points that match a user-defined pattern from body surface (BS) ECG signals or from unipolar intracardiac (IC) electrograms.

A pattern is a collection of signals captured in a single beat. The *pattern of interest (POI)* is the section of the pattern representing the desired activation. The system automatically suggests a POI based on the pattern type and reference channel.

When a pattern is captured, a reference annotation is calculated according to the reference channel and criterion of the Active Map. When a pattern is selected as an Acquisition Filter, the reference annotation of each real-time beat is aligned with the reference annotation of the Pattern, and the real-time signals enclosed by the POI is used for calculating the weighted correlation value. It is recommended to use the same reference channel and criterion on both the pattern and the map.

* BS Pattern: Weighted correlation is calculated based on the 12-lead ECG.
* IC Pattern: Weighted correlation is calculated based on the selected unipolar channels on the reference catheter electrode. (The default is 10 channels.)

The typical Pattern Matching workflow consists of the following activities:

* Capturing and defining a pattern (see ["Capturing Patterns"](#target9000002) and ["Defining and Editing Patterns in the Pattern Bank"](#target9000003))
* Setting a pattern filter for Continuous Mapping (see ["Setting the Pattern Matching Filter"](#target9000004))
* Optional: Comparing real-time signal with the captured pattern (see ["Viewing the Active Pattern"](#target9000005))
* Optional: Start a new map with a name based on the captured pattern (see ["Creating New Map from Pattern Capture"](#target9000006))

### Capturing Patterns

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_patternMatch\_capture\_v7p5\_EN.xml

|  |  |
| --- | --- |
| 1. | Use the menu on the Pattern Capture button to select the pattern type: body surface (BS Pattern) or intracardiac (IC Pattern). The IC Pattern option is only available when the reference annotation is intracardiac.  ![PM_capture_options_v75.png](data:image/png;base64...)  The Pattern Capture button shows the current status. ![PM_capture_IC_icon.png](data:image/png;base64...) |
| 2. | Click the Pattern Capture button.  62.5 seconds of recorded data are captured. The Pattern Bank window opens, with the automatically suggested POI.  ![pattern_bank_window_v8.png](data:image/png;base64...)  The system assigns each captured pattern a name that consists of the pattern type (IC PTRN or BS PTRN) and a number. |

The System automatically determines the POI according to the pattern type.

**Body Surface Patterns (BS PTRN):**

* For body surface reference channels, the POI is set from earliest onset to latest offset of the 12 ECG leads surrounding the reference annotation.
* For IC reference channels:
  + Automatic Reference Criterion (ARA): POI is set around ventricular activation closest to the latest annotation
  + Other reference criterion: POI is set around the onset and offset of the activation surrounding the selected IC reference annotation

**Intracardiac Patterns (IC PTRN):** The POI is automatically set from earliest onset to latest offset of the selected unipolar channels, surrounding the selected beat's reference annotation.

* Automatic (ARA) Reference Criterion: The POI is suggested around latest reference annotation with a minimum of 100 ms between atrial and ventricular activation.
* Other IC Reference Criterion: POI is suggested around the latest reference annotation, regardless of the chamber of activation.
* Pacing reference: POI is suggested around the latest reference annotation (i.e., pacing spike).

The system can store up to 40 captured patterns per study, including body surface patterns, intracardiac patterns, and Induced Signals (PASO™ Module). To capture additional patterns, delete existing patterns. (This limit does not include patterns that are copied in the CONFIDENSE™ Module.)

### Interaction with the PASO™ Module

https://bwiildita.sharepoint.com/sites/prod/Topics/continuous\_patternMatch\_paso\_7p3\_EN.xml

In general, the Pattern Matching filter in the CONFIDENSE™ Module functions independently from the PASO™ Module. However, if both modules are installed, captured body surface signals (IS/BS PTRN) appear in both the Pattern Bank and the IS List.

* The pattern in the Pattern Bank and the signal in the IS List will have the same number, but different prefixes. For example, the third capture will become BS PTRN 3 and IS 3.
* Numbering is global and cannot be edited.
* The global number increases by 1 each time a signal/pattern is captured.
* The global number increases by 1 any time a signal/pattern is duplicated/copied in either the pattern bank or the IS List. However, a copied IS signal does not appear in the pattern bank and a copied pattern does not appear in the IS List.
* The global number does not change if a signal is deleted from either list.
* Once the signal and pattern appear in their respective banks, they are independent. For example, edits to BS PTRN 3 do not affect IS 3.
* Captures during the setup phase (before moving to the Mapping phase) appear only in the IS List. For example, if there are 3 captures during setup and then one when mapping starts, the IS List has 4 signals, but the pattern list has only 1 signal: BS PTRN 4.

The pattern of interest may be different in the two modules. The default POI in Pattern Matching is set to the last annotation.

REP4611 v6 tab, pattern matching

The two modules use different methods to calculate correlation. Therefore, the same data can yield different results in each module.

# Wavefront Mapping Annotation

https://bwiildita.sharepoint.com/sites/prod/Topics/signalAnotation\_wavefrontMappingIntro\_v8\_EN.xml

The **Wavefront Mapping Annotation** uses an algorithm to evaluate unipolar signals for the greatest negative deflection (‑dV/dt). To use this algorithm, select Wavefront as the Mapping Criterion in the Map Setup screen.

For each paired bipolar signal, both distal and proximal electrodes are evaluated. The mapping annotation is set on the unipolar signal with the greatest negative deflection. The point's location is on the electrode from which the mapping annotation was identified.

If a Wavefront Mapping Annotation is not identified, the system evaluates the point candidate to determine whether to add to the map as a no-LAT point. The point candidate is then added as a no-LAT point if the following conditions are met:

* There was no Wavefront candidate in the previous beat
* The electrode was in close proximity for both current and previous beats (given that the Tissue Proximity filter is active)
* The point candidate passes the position stability and bipolar voltage thresholds

No-LAT points are marked in gray and do not affect the LAT coloring of the map.

The position stability and bipolar voltage thresholds depend on the selected chamber.

* Position stability:
  + Equal to or less than 4 mm when the Chamber of Interest selected in the Map Setup screen is either Left Atrium or Right Atrium
  + Equal to or less than 8 mm when the Chamber of Interest selected in the Map Setup screen is either Left Ventricle or Right Ventricle
* Bipolar voltage:
  + Equal to or less than 0.1 mV when the Chamber of Interest selected in the Map Setup screen is either Left Atrium or Right Atrium
  + Equal to or less than 0.5 mV when the Chamber of Interest selected in the Map Setup screen is either Left Ventricle or Right Ventricle

If the point candidate does not meet all these criteria, it is not added to the map.

A **Ripple Map** is a dynamic display of bipolar electrogram data in an electroanatomical map. ## Marking Points

https://bwiildita.sharepoint.com/sites/prod/Topics/RippleMap\_MarkPoints\_v6\_EN.xml

Ripple markers can be added to points for easy reference. When you mark a point, you see the following:

* In the map: a fixed, colored bar on the point
* In the Ripple Viewer: the bipolar channel of the point in the same color as the bar

The Ripple Viewer is a dedicated viewer for the bipolar mapping channels of marked points together with the BS ECG lead II of the point that was acquired first. Mapping channels from different acquisitions and different maps can be displayed. The reference annotation of each marked point is aligned along the red, dotted reference line in the signal viewer. When a marker is selected on the map or the corresponding electrogram is selected in the Ripple Viewer, the point is also selected to enable easy review of the electrograms in the Selected Point Viewer.

The BS ECG lead II cannot be removed from the Ripple Viewer. Other leads cannot be displayed.
