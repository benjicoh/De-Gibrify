# CARTO PRIME™ Module Overview

https://bwiildita.sharepoint.com/sites/prod/Topics/prime\_modules\_overview\_EN.xml

The CARTO PRIME™ Module combines the following advanced mapping features:

* The **CARTOFINDER™** Module provides automatic analysis of multiple, simultaneous intracardiac (IC) signals and enables the creation of high density dynamic maps.

See ["CARTOFINDER™ Module"](#target9000001).

* **Coherent Mapping** is a CARTO™ 3 System feature that improves the representation of the electric wave propagation over the atria by means of coloring and direction vectors, focusing on the displayed path of cyclic arrhythmia propagation. The reconstruction includes detection of areas with probable conduction barriers (slow or no conduction).

See ["COHERENT Mapping"](#target9000002).

* **Parallel Mapping** can be used for continuous mapping of up to 4 maps with different map settings and different acquisition filters. For example, different acquisition filters can be used for different settings, such as cycle length, signal morphology, etc. In addition, acquired data can be recalculated retrospectively according to different acquisition filters.

See ["Parallel Mapping"](#target9000003).

* **LAT Hybrid** maps provide a solution for PVC mapping by creating a hybrid point: the coloring reflects the LAT value during PVC rhythm, and the location corresponds to the location during sinus rhythm.

See ["LAT Hybrid Maps"](#target9000004).

* **Map Merge** is an enhanced way to load maps from a previous study with VISITAG™ and ablation data, and view them together with current study maps. Using maps from previous studies in a current active map allows you to navigate the catheter to areas of interest from previous ablations and identify areas where the study may need to be re-evaluated.

See ["Map Merge"](#target9000005).

# CARTOFINDER™ Module

https://bwiildita.sharepoint.com/sites/prod/Topics/CFinder\_intro\_v7\_EN.xml

The **CARTOFINDER™** Module provides automatic analysis of multiple, simultaneous intracardiac (IC) signals and enables the creation of high density dynamic maps.

The CARTOFINDER™ algorithm analyzes the recorded ECG data and calculates annotations on the unipolar IC signals, allowing the detection and display of electrical activation patterns in atrial arrhythmias in a dynamic fashion. The CARTOFINDER™ Module expands the CARTO™ 3 System mapping capabilities to include irregular activation and possible identification of repetitive focal and rotational activation patterns. When one of the CARTOFINDER™ map coloring types is selected, the CARTOFINDER™ sites contribute to the coloring on the map surface.

V7 REP9626\_1.4: 1.5.8

The CARTOFINDER™ Module uses input from a PENTARAY™ NAV Catheter connected to the PIU.

### Recording CARTOFINDER™ Module Data

https://bwiildita.sharepoint.com/sites/prod/Topics/CARTOFINDERInterface\_v7\_EN.xml

The CARTOFINDER™ recording button in the Acquisition Panel is hidden by default. To enable CARTOFINDER™ recording, click Tools > CARTOFINDER™ Module On. The recording button is added to the Acquisition Panel. (This does not affect other CARTOFINDER™ Module options. They are always available if the CARTO PRIME™ Module is installed.)

The recording button is disabled during the following situations:

* No supported catheter is connected to the system
* A supported catheter is not selected as the mapping catheter
* The system is in an error state
* There is a disconnection in the body surface electrodes
* FAM acquisition is active

During CARTOFINDER™ recording, you cannot perform the following actions:

* New Map
* Remap
* Save Map As
* Map Replay
* Copy Point To or Move Point To
* FAM acquisition or continuous EA acquisition

### Viewing CARTOFINDER™ Sites

https://bwiildita.sharepoint.com/sites/prod/Topics/CARTOFINDERViewingSites\_v7\_EN.xml

The algorithm receives data from the recording and detects CARTOFINDER™ sites. A CARTOFINDER™ site, which is a collection of ECG data acquired during a CARTOFINDER™ recording at the average location of the mapping catheter during recording time, is added on top of the map reconstruction.

A CARTOFINDER™ site in the map functions similarly to a point or contour. Some examples include:

* Selecting a CARTOFINDER™ site in the Main Map Viewer selects the CARTOFINDER™ site in the Point List, Selected Point Viewer, and the Additional Map Viewer (if the same map is active in both map viewers).
* Selecting a CARTOFINDER™ site in the Point List results in display of the CARTOFINDER™ site's signals in the Selected Point Viewer.
* A CARTOFINDER™ site can be deleted, copied, moved, or restored from the map.

A CARTOFINDER™ site is electrical only and does not contribute to the map reconstruction. A CARTOFINDER™ site only contributes to the map coloring of a CARTOFINDER™ Module map.

## About the Coherent Mapping Algorithm

https://bwiildita.sharepoint.com/sites/prod/Topics/CoherentOverview\_algorithm\_v7\_EN.xml

FDA Req. No. K173977/S001 dated February 23, 2018.

The Coherent Mapping algorithm was designed based on the electrophysiological conditions of typical flutter, atypical flutter, and focal atrial tachycardia. In these conditions, conduction velocity is continuous, meaning that there are no sharp turns of wave velocity, except in areas with slow conduction or blocks with tissue properties as defined in the literature. The algorithm uses the Local Activation Time (LAT) values of all the points in a map and performs an iterative calculation for a global solution in these arrhythmias.

The main conditions used by the algorithm are:

* Low potential points such as scar
* Double-potential points
* Dense map of the chamber with uniform distribution of points

For optimal performance, we recommend:

* Scar settings are properly defined according to your clinical practice.
* Signals that you identify as double-potential are tagged as such.
* Map data must be dense enough to allow continuous interpolation of activation between the points.
* Anatomical structures are marked.

The iterative nature of the calculation leads to a global best-fit solution, analogous to calculating a regression line to show how scattered points indicate a global trend.

![coherent_map_diagram_v7.png](data:image/png;base64...)

Figure 20: LAT Coloring (Left) and Coherent Coloring (Right)

In the image above, LAT coloring presents a local solution, where every point has an individual contribution to the map coloring. Coherent coloring presents a global best-fit solution based on all the map points.

# Parallel Mapping

https://bwiildita.sharepoint.com/sites/prod/Topics/parallel-LAT\_UsingPara\_EN.xml

**Parallel Mapping** can be used for continuous mapping of up to 4 maps with different map settings and different acquisition filters.   + EA points are added to the new map according to the new acquisition filters.
  + The map can be recalculated as a Point-by-Point map instead of FAM.
* When the original map is a Point-by-Point map, points are added and anatomy is recalculated according to the new acquisition filters.
* The map data is evaluated from the beginning of acquisition. Stopping the calculation does not cancel the acquisition. Instead, points that were already identified are added to the map.

**Additional map data:**

* Tagged points are copied as Location Only points (similar to Remap).
* CARTOFINDER™ Module sites are not copied.

**Ablation data:**

* Ablation sessions from the original map are duplicated, and ablation tags are copied to the recalculated map.
* The acquisition filters are not applied for the duration of any ablation sessions in the original map.
* VISITAG™ Sites are displayed in the recalculated map.

# LAT Hybrid Maps

https://bwiildita.sharepoint.com/sites/prod/Topics/parallel-LAT\_UsingLAT\_EN.xml

Transient changes in the heart rhythm, such as PVC, can lead to catheter displacement compared to normal sinus activation. **LAT Hybrid** maps provide a solution for PVC mapping by creating a hybrid point: the coloring reflects the LAT value during PVC rhythm, and the location corresponds to the location during sinus rhythm.

This feature relies on Continuous Mapping acquisition filters. For details, refer to the *CONFIDENSE™ Module User Guide*.

### Evaluation of Automatically Acquired Points

https://bwiildita.sharepoint.com/sites/prod/Topics/parallel-LAT\_automatic\_LAT\_EN.xml

When Continuous Mapping is active, the System automatically evaluates each potential point against the acquisition filters. The sequence below describes the process.

* Find a potential PVC point, according to the Activation pattern.
* Confirm that the previous beat matches the normal sinus rhythm, according to the Location pattern.
* The Position Stability and LAT Stability filters are applied to two consecutive sinus beats prior to the PVC beat.
* Evaluate remaining filters on the sinus beat.

If any active filter fails, the point is discarded.

In a LAT Hybrid map, the Filters Status toolbar is updated to show both the PVC and NSR filter status. To view either pattern in the pattern viewer, click the status box.

### Manually Acquired Points

https://bwiildita.sharepoint.com/sites/prod/Topics/parallel-LAT\_manual\_LAT\_EN.xml

LAT Hybrid points can be acquired manually.

After you acquire a point and select the PVC beat in the beat buffer, the System searches the 5 beats prior to the selected PVC beat for a sinus beat based on the Location pattern. If no sinus beat is found, the PVC beat is also assigned as the location beat. This point will be marked in the point list as a non-hybrid point.

If the Respiration Gated filter is active, the System searches for an end-expiration sinus beat within 5 beats prior to the PVC beat. If no match is found, the PVC point is assigned as a non-hybrid point.

If the Tissue Proximity filter is active, it is applied to the sinus beat.

Non-hybrid points are marked with a red cross in the map. They are floating points, which do not affect map anatomy or coloring. The type can be changed through the point's right-click menu.

If a point is acquired manually during ablation, activation and location will be assigned to the same beat. The Ablation tag is applied.
